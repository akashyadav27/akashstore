# 🛒 AkashStore — Full Stack E-Commerce App

A fully functional e-commerce web application built with React, Node.js, Express and MySQL.

## 🚀 Features

- User registration and login with JWT authentication
- Browse and search products by category
- Shopping cart with quantity management
- Checkout and order placement
- User profile with order history
- Admin dashboard to manage products and orders
- Protected routes for authenticated users and admins

## 🛠️ Tech Stack

**Frontend:**
- React.js
- Tailwind CSS
- React Router DOM
- Axios

**Backend:**
- Node.js
- Express.js
- MySQL
- Sequelize ORM
- JWT Authentication
- Bcrypt.js

## ⚙️ Getting Started

### Prerequisites
- Node.js
- MySQL

### Backend Setup
cd backend
npm install
create .env file with your credentials
npm run dev

### Frontend Setup
cd akashstore-frontend
npm install
npm start
